Setup:  
In a folder, initialize node js:  
```bash
npm init
```  
Install discord.js & mysql:  
```bash
npm install discord.js
npm install sqlite3
```  
In the "config.json" file, change the token to yours,  
In the index_PoopCounter.js file, change the information at the top of the code according to your needs.  
To launch the bot, execute:  
```bash
node index_PoopCounter.js
```
